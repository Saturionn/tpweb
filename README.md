Mini Bug-Tracker
Projet de suivi de tickets développé avec Vue.js 3, TypeScript et Tailwind CSS, connecté à une API Symfony (Docker).
Lancement du projet
Installer les dépendances :
```bash
npm install
```
S'assurer que le conteneur Docker du back-end est bien lancé (sur le port 8000).
Lancer le serveur de développement :
```bash
npm run dev
```
L'application est ensuite accessible sur `http://localhost:5173`.
